Assignment: 

Deploy a Low-Cost Website Using Kubernetes

Tasks to be Completed:

1. Purchase a ₹1 domain or a free/low-cost domain from any domain provider.
2. Set up a Kubernetes cluster (Minikube, Kind, EKS, AKS, or any cloud/local setup).
3. Create a simple static website using HTML (optional: CSS).
4. Create a Dockerfile to containerize the website.
5. Build the Docker image for the website.
6. Push the Docker image to a container registry (Docker Hub / ECR / ACR / GCR).
7. Create a Kubernetes namespace for the application.
8. Create a Kubernetes Deployment with multiple replicas (pods).
9. Verify that the pods are running successfully.
10. Create a Kubernetes Service to expose the application (NodePort or LoadBalancer).
11. Access the website using the Service IP/Port.
12. Configure DNS settings to map the purchased domain to the Kubernetes Service.
13. Verify that the website is accessible using the domain name.
14. Scale the Deployment (increase and decrease the number of pods).
15. Validate high availability by checking load distribution across pods.
16. Document all steps, commands, and configurations used.
17. Submit Kubernetes YAML files, Dockerfile, and the live website URL.
